## Overview

**Finora** is a full-stack budget tracking application developed using **React.js, Java Spring Boot, and MySQL**. It provides a streamlined platform for managing personal finances, tracking transactions, and monitoring financial activities.

## Features

- **Transaction Management** — Add, edit, and delete income and expense records.
- **Financial Dashboard** — Monitor income, expenses, and available balance.
- **Transaction Filtering** — Filter financial records by category, type, and date.
- **RESTful API** — Enable communication between frontend and backend.
- **Database Management** — Securely store and manage financial records using MySQL.
- **Responsive Design** — Optimized for desktop and mobile devices.
